# Detecção de Fraudes em Cartão de Crédito

Projeto Integrador VI — PUC-Campinas.

## Como rodar
1. `python3 -m venv venv` e `source venv/bin/activate`
2. `python -m pip install -r requirements.txt`
3. Baixe o dataset Credit Card Fraud Detection (Kaggle) e salve em `data/creditcard.csv`

## Estrutura
- `notebooks/`: análise exploratória e modelagem
- `ml/`: código do modelo em Python
- `resultados/`: gráficos e tabelas
- `modelos/`: modelos treinados (não vão para o Git)
